# Estudos em Linguagem C

Repositório dedicado aos meus estudos e à prática de programação em **linguagem C**, com exercícios e pequenos projetos desenvolvidos durante minha formação em Ciência da Computação.

O objetivo é consolidar os fundamentos da programação, desenvolver o raciocínio lógico e praticar conceitos como estruturas de repetição, vetores, matrizes, ponteiros e estruturas de dados.

## 📚 Conteúdos estudados

### Fundamentos
Exercícios introdutórios para praticar lógica de programação e operações básicas.

- Cálculo de média e soma;
- Verificação de números pares e ímpares;
- Classificação de números positivos, negativos e nulos;
- Estruturas de repetição e contagem;
- Calculadora e operações com intervalos;
- Ordenação de vetores.

### Vetores e matrizes
Implementação de exercícios para manipulação de coleções de dados e operações matriciais.

- Leitura e exibição de matrizes;
- Busca de valores;
- Soma de linhas, colunas e diagonais;
- Soma, diferença e multiplicação de matrizes;
- Multiplicação escalar;
- Matriz transposta;
- Classificação de valores;
- Construção de padrões numéricos;
- Borda e região interna de matrizes;
- Quadrado mágico;
- Batalha naval e jogo da velha com matrizes.

### Ponteiros
Exercícios para compreender o uso de ponteiros e o acesso indireto à memória.

- Declaração e utilização de ponteiros;
- Manipulação de variáveis por meio de endereços de memória.

### Structs e projetos
Prática de organização de dados e desenvolvimento de programas com múltiplos arquivos.

- **Biblioteca:** exercício de programação utilizando estruturas em C;
- **Gestão de alunos:** projeto organizado em arquivos de implementação, declaração e programa principal.

## 🛠️ Tecnologias e ferramentas

- Linguagem C;
- Visual Studio Code;
- Compilador GCC ou outro compilador compatível com C.

## ▶️ Como executar os programas

1. Clone o repositório:

   ```bash
   git clone URL_DO_REPOSITORIO
   ```

2. Entre na pasta do projeto:

   ```bash
   cd NOME_DO_REPOSITORIO
   ```

3. Compile um arquivo `.c` utilizando o GCC. Por exemplo:

   ```bash
   gcc src/fundamentos/Ex_1_media.c -o media
   ```

4. Execute o programa compilado.

   No Windows:

   ```bash
   .\media.exe
   ```

   No Linux:

   ```bash
   ./media
   ```

**Observação:** ajuste o caminho do arquivo conforme a estrutura real do repositório. Para projetos divididos em vários arquivos, compile todos os arquivos `.c` necessários no mesmo comando.

## 🎯 Objetivos de aprendizagem

- Fortalecer a lógica de programação;
- Desenvolver autonomia na resolução de problemas;
- Compreender os fundamentos da linguagem C;
- Praticar estruturas de controle, vetores, matrizes, ponteiros e structs;
- Construir uma base sólida para disciplinas de programação e algoritmos.
